Typography refresh — 2026-10-15

Main family: DM Sans, variable weights and optical sizing, normal and italic.
Source: https://fonts.google.com/specimen/DM+Sans
Loaded through next/font/google and self-hosted in the Next.js build.

Secondary family: existing Geist Mono for wordmark, ticket metadata and chapter
controls. Two font families total; no external font request at page runtime.

Display tracking is relaxed from the previous -0.06/-0.065em values to -0.045em,
and -0.035em on compact layouts. Secondary headings use -0.035/-0.02em.
Medium navigation, button and section label weights create a clear hierarchy.
Existing responsive text sizes and paragraph line heights are preserved.

Original text, black/cream theme, viewport navigation and official images stay
unchanged. Only font loading and typography styles are edited.
