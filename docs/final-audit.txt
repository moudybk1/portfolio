Finalisasi dan audit portfolio — 15 Oktober 2026

Ruang lingkup
Pemeriksaan source, build production, dependency, route publik/admin, database,
interaksi browser, layout responsif, dan keutuhan copy. Ini audit fungsional dan
dependency, bukan sertifikasi keamanan, aksesibilitas, atau semua browser.

Bug yang ditemukan dan diperbaiki
1. Login development: validasi minlength 8 menghalangi password bawaan development
   yang berisi 5 karakter. Validasi client diselaraskan dengan autentikasi server.
2. Setelah respons rate limit, form login sebelumnya terus disabled. Sekarang
   disabled hanya selama request; pembatasan login tetap ditegakkan server.
3. Kegagalan inisialisasi database pertama membuat promise tersimpan selalu gagal.
   Promise direset saat gagal sehingga request berikutnya dapat mencoba kembali.
4. Perubahan judul artikel sebelumnya mengganti slug dan merusak tautan lama.
   URL artikel sekarang tetap ketika judul diedit.
5. Judul yang tidak menghasilkan karakter slug Latin berulang mendapat suffix
   tanpa stem. Fallback kini konsisten: untitled, untitled-2, dan seterusnya.
6. Dua createPost bersamaan dengan judul sama menimbulkan UNIQUE constraint error.
   INSERT kini menangani konflik slug secara atomik dan mencoba suffix berikutnya.
7. ID artikel tidak valid dapat masuk ke driver database. ID bukan bilangan bulat
   positif yang aman kini diperlakukan sebagai artikel yang tidak ditemukan.
8. Tag kosong/berulang menghasilkan badge kosong dan key React duplikat. Render
   tag kini memangkas whitespace, menghapus tag kosong, dan menghapus duplikasi.
9. Hero, Approach dan AI Playground melampaui frame pada 320x568. Hero, Work,
   Approach dan Toolkit melampaui frame pada landscape kecil. Spasi, grid,
   ukuran media, dan breakpoint diperbaiki tanpa mengubah copy.
10. Writing dengan tiga artikel melampaui satu viewport pada mobile. Preview
    mendapat pager pada layar compact; desktop tinggi tetap menampilkan tiga
    artikel. Artikel yang tidak aktif inert dan tidak masuk urutan fokus.
11. Hash section baru pada homepage yang sudah terpasang tidak memindahkan panel.
    HomeScrollHandler kini menangani hashchange serta mempertahankan state router
    dan query string saat membersihkan hash yang sudah ditangani.
12. Hash transaksi panjang pada artikel membuat dokumen melebar. Pembungkusan teks
    panjang diperbaiki; blok code tetap memiliki scroll horizontal sendiri.
13. Judul tab admin menggandakan nama Moudy. Judul child kini memakai template root.
14. Dimensi metadata OG tidak sesuai gambar asli. Diubah menjadi 1024x571.
15. Next.js memberi warning terkait CSS smooth scroll. Root html kini memuat
    data-scroll-behavior sesuai dokumentasi Next.js yang terpasang.

Route dan lifecycle admin
- 12 pemeriksaan HTTP production lolos: homepage, daftar artikel, tiga artikel
  published, draft 404, artikel tidak ada 404, tiga route admin tanpa autentikasi
  redirect ke login, robots.txt, dan sitemap.xml.
- Route admin memiliki Cache-Control no-store, no-cache, must-revalidate, private.
- Draft tidak muncul di isi respons publik maupun sitemap.
- Login development memakai input keyboard nyata berhasil.
- Login production berhasil dengan konfigurasi QA sementara dan cookie secure.
- Rate limit disimulasikan di database QA: respons lock ditolak server; setelah
  expiry disimulasikan, form yang sama bisa login tanpa reload.
- Browser admin: create draft -> publish -> buka artikel -> edit judul dengan URL
  lama tetap 200 -> unpublish menjadi 404 dan hilang dari sitemap -> logout.
- Sesudah build final, create dengan judul yang sama berhasil mendapat suffix -2.
- Penghapusan data diuji hanya lewat tes database sementara.
- Database utama dan artikel asli tidak diubah. Server QA, database QA, dan secret
  sementara sudah dibersihkan. Dev server utama tetap di http://127.0.0.1:3000/.

Batas pemeriksaan dan tindak lanjut
- Dua advisory tooling development di atas masih terbuka; cek pembaruan upstream.
- Tidak menguji koneksi Turso sesungguhnya atau deployment/HTTPS eksternal.
  Konfigurasi production AUTH_SECRET, ADMIN_PASSWORD dan database belum tersedia
  di environment lokal utama; pengujian production memakai konfigurasi QA sendiri.
- Layout menggunakan viewport browser; bukan pengujian perangkat iOS/Android fisik
  atau seluruh Safari/Firefox. Gesture touch dan reduced motion ditinjau di source,
  tanpa emulasi preferensi reduced motion pada browser audit ini.
- Copy artikel arbitrer yang sangat panjang tetap memakai fallback scroll di panel.
  Satu viewport sudah diverifikasi untuk copy portfolio dan fixture yang diuji;
  ukuran teks aksesibilitas ekstrem tidak dijanjikan muat tanpa scroll.
- Tidak ada pengukuran Lighthouse baru atau klaim skor performance.
- Tidak ada commit, push, atau deployment pada finalisasi ini.
